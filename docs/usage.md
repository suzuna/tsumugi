# 使い方

## 起動

```sh
tsumugi              # 無題のバッファで起動
tsumugi foo.txt      # ファイルを開く（存在しなければ新規ファイルとして開く）
tsumugi a.txt b.txt  # 複数ファイルをタブで開く
tsumugi ~/repos/foo  # ディレクトリを開く（ツリーの起点にして、そこへ cd する）
```

ツリーの起点は、起動したディレクトリ（ディレクトリを渡したらそのディレクトリ）になる。ディレクトリは1つまで渡せて、ファイルと一緒にも渡せる（`tsumugi ~/repos/foo a.txt` の `a.txt` は、起動したシェルのディレクトリから数える）。

## キーバインド

基本は micro と同じ。全部のキーは Ctrl+G のヘルプで見られる。micro と違うのはこれだけ。

| キー | tsumugi | micro |
|---|---|---|
| Ctrl+O | ディレクトリを開く（パスを入力） | ファイルを開く |
| Ctrl+B | ファイルエクスプローラ（オーバーレイ） | シェル実行 |
| Ctrl+E | サイドバーのツリーを表示 / 非表示 | コマンドバー |
| Ctrl+L | 今のファイルの絶対パスをコピー。ツリーにフォーカスがあればカーソル位置のファイル / ディレクトリの絶対パス | 行ジャンプ |
| Ctrl+W | 今のタブを閉じる（最後の1枚なら空の無題タブを残す） | 分割の移動 |
| Ctrl+Q | 全部のタブを閉じて終了（未保存のタブは1つずつ保存するか聞く） | 今のタブを閉じる（最後なら終了） |
| Ctrl+U | 分割したペインの間でフォーカスを移動 | マクロの記録 |
| Ctrl+J | サイドバーのツリーとペインの間でフォーカスを移動 | マクロの再生 |
| Ctrl+\ | 分割なし → 左右 → 上下 → 分割なし と切り替え | なし |
| Ctrl+] | 今のタブを隣のペインへ移す | なし |
| Ctrl+R | 置換（1件ずつ確認） | ルーラーの切替 |
| Ctrl+PgUp / Ctrl+PgDn | 前 / 次のタブ | なし |
| Alt+, / Alt+. | 前 / 次のタブ。ただし kitty keyboard protocol 対応ターミナルで `TEXTUAL_DISABLE_KITTY_KEY=0` を付けて起動したときだけ | 前 / 次のタブ |

ほかの違い。

- コマンドバー、プラグイン、マクロ、マルチカーソルはない
- 分割は2つまで。分割の仕方は micro と違う（下の「分割」を参照）
- 行ジャンプはない（Ctrl+L はパスのコピーに使っている）
- 検索は大文字小文字を区別する部分一致（正規表現なし）
- 無題のバッファを保存するとき、相対パスは今開いているディレクトリ（ツリーの起点）が基準になる
- 開けるのは UTF-8 のテキストファイルだけ
- Enter で改行すると、今の行の先頭の空白（スペース・タブ）を新しい行に引き継ぐ。改行したあと今の行が空白だけになるなら、その空白は消す
- 開いているファイルがディスク上で書き換えられたら、未編集なら自動で読み直す。編集中なら下段に知らせ、保存するときに上書きしていいか聞く

kitty keyboard protocol は既定でオフにしている。iTerm2 などでは IME の確定が kitty の形式で届き、日本語が入力できなくなるため。

## シンタックスハイライト

ファイル名と拡張子（拡張子がなければ1行目の shebang）から言語を決めて色を付ける。

- Python、Rust、Go、JavaScript、Bash、JSON、TOML、YAML、Markdown、HTML、CSS、SQL、Java、XML は Textual が持っている文法を使う
- それ以外の言語（R、Stan、TypeScript、C など）は tree-sitter-language-pack の文法を使う。その言語を初めて開くときに文法をダウンロードし、`~/Library/Caches/tree-sitter-language-pack/`（macOS の場合）に置く。ダウンロードが終わるまでは色が付かない。ダウンロードできなかったら下段に知らせ、tsumugi を起動し直すまでその言語には色を付けない
- `.qmd` と `.Rmd` は Markdown として扱う。Markdown の中のコードブロックは、中の言語では色分けせず、コードとして1色で表示する
- 行数が `highlight_max_lines`（既定は 3000）より多いファイルは、重くなるので色を付けない（[設定](config.md)）
- 言語と行数を見るのは、開くとき・ディスクから読み直すとき・名前を付けて保存したとき・リネームしたときだけ。編集で行数が上限をまたいでも、色を付けたり消したりはしない

## タブ

- タブのファイル名は表示幅20マスまで。長い名前は真ん中を `…` にして省略する（拡張子が残るよう後ろを少し多めに残す）。未保存の印 ` +` は省略せず後ろに付ける
- タブがタブバーに入りきらないときは、選んでいるタブが見えるよう、タブ1枚単位で左のタブを隠して横にずらす

## 分割

エディタを2つのペインに分けて、別々のファイルを並べて見られる。ペインはそれぞれ自分のタブの列を持ち、タブはどちらか片方のペインに属する（micro のようにタブの中を分割するのではなく、VS Code のようにペインの中にタブがある）。

- Ctrl+\ を押すたびに、分割なし → 左右 → 上下 → 分割なし と切り替わる
- 分割すると、今のタブが新しいペイン（右）へ移る。元のペインにタブが残らなければ、空の無題バッファを開く
- 分割をやめると、右 / 下のペインのタブを左 / 上のペインの後ろにまとめる。空の無題バッファは、ほかにタブがあれば閉じる
- Ctrl+] で今のタブを隣のペインへ移す。分割していなければ、左右に分割して移す。移したせいでペインが空になったら分割をやめる
- タブはマウスでドラッグして動かせる。同じタブバーの上で離したら並べ替え（離したタブの位置に入る。タブより右なら末尾）、隣のペインのタブバーに離したらその位置へ、隣のペインのエディタ部分に離したら末尾へ移す。分割していないときにエディタ部分へ離しても何もしない
- Ctrl+U で左 / 上と右 / 下のペインの間をフォーカスが移る。サイドバーには行かない
- Ctrl+J でサイドバーのツリーとペインの間をフォーカスが移る。ツリーから戻るときは最後に操作していたペインへ戻る。サイドバーが出ていなければ何もしない
- 新しいタブ、ファイルを開く、タブの切り替え（Ctrl+PgUp / Ctrl+PgDn など）は、今のペインの中で行う。サイドバーから開いたファイルは、最後にフォーカスしていたペインに開く
- 同じファイルは片方のペインにしか開かない。もう一方のペインで開いているファイルを開くと、そのペインのタブへ移る
- ペインの最後のタブを閉じると、分割をやめる
- 移したタブも、編集中の内容や undo の履歴、カーソル位置はそのまま

## 置換

Ctrl+R で `Replace: ` に探す文字列、`Replace with: ` に置き換える文字列を入れる（置き換える文字列は空でもよく、そのときは消える）。一致するところを1件ずつ選択して `Replace? (y,n,a,esc)` と聞く。

| キー | 動作 |
|---|---|
| y | 置き換えて次へ |
| n | 置き換えずに次へ |
| a | 残りを全部置き換えて終わる（まとめて1回の undo で戻る） |
| Esc | やめる（それまでに置き換えたぶんは残る） |

選択中なら選択範囲の中だけ、選択していなければカーソル位置から末尾まで見て、先頭に折り返してカーソル位置の手前まで見る。探し方は検索と同じで、大文字小文字を区別する部分一致（正規表現なし）。探した文字列は検索にも引き継ぐので、あとで Ctrl+N / Ctrl+P で探せる。

## エクスプローラ

ツリーは micro の filemanager と同じ書き方で、ディレクトリは `+ name/`（閉）/ `- name/`（開）、ファイルは字下げだけで表示する。

```
~/repos/tsumugi
+ src/
- tests/
    test_app.py
  README.md
```

Ctrl+B では画面中央にオーバーレイで出て、ファイルを選ぶと閉じる。Ctrl+E では左の列に出て、ファイルを選んでもフォーカスはツリーに残る。どちらも最後にいたディレクトリ（最初は起動したディレクトリ）から開き、選んだファイルは新しいタブで開く（空の無題バッファは置き換え、開いているファイルならそのタブへ切り替え）。

ツリーの起点は、今開いているディレクトリ（カレントディレクトリ）といつも同じ。Backspace で親へ上がる、`o` でカーソルのディレクトリに入る、Ctrl+O でパスを入れる、オーバーレイで `g` を押してパスを入れる、のどれでも起点が変わり、カレントディレクトリもそこへ移る。ステータスバーのパスも新しいディレクトリからの相対パスになる。ファイルを開くだけでは起点は変わらない。起点はオーバーレイとサイドバーで共有する。オーバーレイでは `o` を押すとそのまま閉じてメイン画面がそのディレクトリになり、Backspace で上がった分は閉じたときに反映される。

Ctrl+O の入力欄には今の起点が入っている。`~` が使えて、相対パスは今の起点から数える。ディレクトリでないパスを入れたら何もしない。サイドバーの表示 / 非表示はそのままで、表示していればツリーが切り替わる。

オーバーレイで `g` を押すと、枠の下に `Go to:` の入力欄が出る。入力欄には今の起点が入っていて、`~` が使え、相対パスはオーバーレイの今の起点（Backspace で上がっていればそこ）から数える。Enter で確定すると、そのディレクトリを起点にしてオーバーレイを閉じる。ディレクトリでないパスなら入力欄の下にエラーを出して、そのまま入力を続けられる。空のまま Enter か Esc で入力欄だけ閉じてツリーに戻る。入力中はツリーのキー（`o` や `s` など）は効かない。

ツリーは0.5秒ごとにディスクと見比べて、ほかのプロセスが足したり消したりしたファイルを反映する。展開状態とカーソル位置はそのまま残る。

| キー | 動作 |
|---|---|
| Enter / クリック | ファイルを開く・ディレクトリを展開 |
| → / ← | ディレクトリを展開 / 閉じる（閉じたものの上なら親へカーソル移動） |
| Backspace | 親ディレクトリを開く |
| o | カーソルのディレクトリに入る（起点にする）。オーバーレイではそのまま閉じる。ファイルの上では何もしない |
| g | パスを入れてディレクトリを開く（オーバーレイのみ）。確定すると閉じる |
| . | 隠しファイルの表示切替 |
| s | 名前の昇順 / 降順を切り替え |
| r / F2 | 名前を変える（サイドバーのみ）。開いているファイルのタブも付け替える |
| d | ゴミ箱へ移す（サイドバーのみ。macOS の `trash` コマンドを使う） |
| m | ディレクトリを作る（サイドバーのみ）。カーソルがディレクトリならその中、ファイルならその隣。`a/b` で入れ子も作れる |
| Ctrl+L | カーソル位置のファイル / ディレクトリの絶対パスをコピー |
| Esc / Ctrl+B | 閉じる（オーバーレイのみ） |
